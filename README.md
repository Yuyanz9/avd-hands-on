# AVD Hands-on package

このリポジトリは、別管理の当日用 PowerPoint を補完する技術資材です。講座の説明・演習手順・実行条件は PowerPoint と講師の指示に従ってください。PowerPoint はこのリポジトリに含めず、このパッケージ単独では使えません。

## Deploy entry points

Deploy ボタンは技術的な入口のみです。PowerPoint と講師の指示なしに実行しないでください。
